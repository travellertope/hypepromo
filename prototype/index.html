SYSTEM ARCHITECTURE SPECIFICATION

HypeQuest Developer & Technical Handbook

Internal engineering reference for web app mechanics, PWA offline configuration, and currency calculations.

1. Financial & CPC Split Algorithm

When an advertiser funds a campaign with a Cost Per Click (CPC) value $C_{gross}$, the system splits the fund as follows:

  • Platform Cut: 15% ($0.15 \times C_{gross}$)
  • Influencer Vault Payout: 85% ($0.85 \times C_{gross}$)

Verified clicks are recorded via edge server web-hooks preventing duplicate bot requests.

2. Anti-Fraud & Click Tracking

Referral links use standard UTM parameters (`?r=user_id&ad=campaign_slug`). The backend validates TLS fingerprints, browser headers, and session TTL before releasing payouts to the loot vault.

3. Progressive Web App (PWA) Setup

Designed to be wrapped via Capacitor or Cordova for iOS/Android distribution, or installed directly through Chrome/Safari mobile browsers using a standard `manifest.json` and Service Worker registration.

4. Local State Management

Client-side reactivity is managed via vanilla JavaScript DOM binding with localStorage persistence for simulated wallet credits, active quest tokens, and XP levels.
